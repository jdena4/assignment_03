#In Part 1 when creating one_package.py I learned how to use guards in streamlit files as well as how to use the parser to read docstrings instead of code. In part 2 (process_file.py) I made my first main mistake. My app crashed on the first load with "AttributeError: 'NoneType' object has no attribute 'name'". The uploader returns None until a file is chosen, and my guard was correct, but the lines that built the JSON path, wrote the file, and showed st.success were at the left margin, so they ran outside the guard on every run. When I fixed the first two, I left st.success outside, which would have caused a NameError because packages and json_path never existed. The lesson is that a guard only protects code that is actually indented under it and I will remember that from now on.
